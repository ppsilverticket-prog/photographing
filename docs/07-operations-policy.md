법과 스토어 정책 때문에 MVP 설계가 달라지는 부분입니다. 와이어프레임 v0.2와 개발 명세에 반영합니다.

### 2-3. 규모가 커지면

전년도 매출 10억 원 이상 **또는** 직전 3개월 일평균 이용자 10만 명 이상이 되면 불법촬영물 필터링(기술적 조치)과 유통방지 책임자 지정 의무가 생깁니다. 2026년 7월부터 이미지도 대상에 들어갔습니다 [24][25]. 사진 앱이라 해당될 때를 미리 대비합니다.

단, 규모와 관계없이 불법촬영물을 신고 등으로 알게 되면 **지체 없이 삭제하거나 접속을 차단할 의무**는 처음부터 있습니다 [26].

## 3. 커뮤니티 가이드라인 (공개 문안 초안)

> **포토그래핑 커뮤니티 가이드라인**
>
> 포토그래핑은 사진 찍는 사람들이 처음 만나 함께 걷고 찍는 곳이에요. 모두가 안심하고 다시 나올 수 있도록 아래 약속을 지켜 주세요.
>
> **사람을 찍을 때**
>
> 1. 모르는 사람을 알아볼 수 있게 찍었다면 먼저 물어보세요. 얼굴이 알아보이는 사진을 올리려면 찍힌 사람의 동의가 필요해요. 공개된 장소에서 찍었다는 이유만으로 올려도 되는 건 아니에요.
> 2. 몰래 찍기, 특정 신체 부위를 노린 촬영, 성적인 목적의 촬영은 금지예요. 확인되면 계정을 바로 영구 정지하고 수사기관에 협조해요.
> 3. 모임에서 서로 찍어 준 사진은 모임 앨범에 올리기 전에 찍힌 사람에게 물어보세요. 내 모습이 나온 사진을 지워 달라고 하면 지워 주세요.
> 4. 아이가 나온 사진은 보호자의 허락 없이 올리지 마세요.
>
> **장소와 사진**
>
> 5. 촬영 금지 구역, 사유지, 출입 통제 구역의 규칙을 지켜 주세요. 모임장은 모임 장소의 촬영 규칙을 미리 확인해 주세요.
> 6. 다른 사람이 찍은 사진을 내 사진처럼 올리지 마세요. 참고 사진을 올릴 때는 찍은 사람을 적어 주세요.
>
> **모임에서**
>
> 7. 못 가게 되면 모임 시작 24시간 전까지 취소해 주세요. 연락 없이 안 나오면 기록이 남고 모임 신청이 제한될 수 있어요.
> 8. 모임은 사진을 찍으러 나온 자리예요. 연락처 교환이나 따로 만나자는 요구를 강요하지 마세요. 상대가 거절하면 거기서 멈춰 주세요.
> 9. 술을 권하거나 모임을 다른 장소로 옮기자고 강요하지 마세요.
> 10. 허락받지 않은 영업, 홍보, 촬영 의뢰 모집은 하지 마세요.
>
> **피드백과 대화에서**
>
> 11. 피드백은 사진에 대해서만 해 주세요. 찍은 사람의 나이, 성별, 장비, 실력을 깎아내리지 마세요.
> 12. 욕설, 혐오 표현, 괴롭힘, 다른 사람을 사칭하는 행동은 금지예요.
>
> **이런 일이 생기면**
>
> 모임 중 위험을 느끼면 먼저 112에 연락하세요. 그다음 모임 화면의 신고 버튼으로 운영팀에 알려 주세요. 불편했던 사람은 차단하면 서로의 모임과 글이 보이지 않아요.
>
> 가이드라인을 어기면 경고, 이용 제한, 영구 정지 순서로 조치해요. 불법 촬영, 성희롱, 폭력, 위협은 경고 없이 영구 정지해요.

## 4. 모임 안전 규칙

### 4-1. 모임 개설

| 규칙 (MVP) | 이유 |
|---|---|
| 본인인증을 마친 사람만 모임을 열 수 있습니다. | 신원 확인 |
| **가입 후 다른 모임에 1회 이상 참석해야 모임을 열 수 있습니다.** 창립 모임장은 예외입니다. | 만든 지 얼마 안 된 계정이 모임을 미끼로 쓰는 것을 막음 |
| 모임은 역 출구, 공원 입구처럼 **공개된 장소에서 모여 시작**합니다. 개인 스튜디오, 숙소, 차량 이동이 포함된 모임은 열 수 없습니다. | 오프라인 안전 |
| **모델을 섭외하는 인물 촬영회는 열 수 없습니다.** 참여자끼리 서로 찍어 주는 인물 스냅은 됩니다. | 출사 분야의 가장 큰 사고·이미지 위험 ([`05`](05-competitor-analysis.md) 5절) |
| 참가비는 무료이거나 장소 대여비 같은 실비만 받을 수 있고, 금액과 용도를 모임 소개에 적습니다. | 유료 결제는 2단계 (2-2절 준비 후) |
| 끝나는 시간을 반드시 적습니다. 저녁 모임은 끝나는 장소도 적습니다. | 야간 출사 안전 |

### 4-2. 참석과 노쇼

- **출석 확인**: MVP는 모임장이 모임 화면에서 참석자를 체크합니다. 모임 종료 후 24시간 안에 체크하지 않으면 전원 참석으로 처리하지 않고 "확인 안 됨"으로 둡니다.
- **취소와 노쇼 기준** (제안값, 베타에서 조정)

| 구분 | 기준 | 기록 |
|---|---|---|
| 정상 취소 | 모임 시작 24시간 전까지 취소 | 기록 없음 |
| 늦은 취소 | 시작 24시간 이내 취소 | 프로필에 횟수 표시 |
| 노쇼 | 연락 없이 불참 (모임장이 체크) | 프로필에 횟수 표시, 참석률 반영 |

| 90일 안의 노쇼 | 조치 |
|---|---|
| 1회 | 알림만 |
| 2회 | 14일 동안 모임 신청 제한 |
| 3회 이상 | 30일 동안 모임 신청 제한, 이후 모임장 승인이 있어야 참여 |

- 모임장이 모임을 일방적으로 취소하면 모임장 참석률에 반영합니다. 날씨 같은 이유는 사유를 적으면 제외합니다.
- 노쇼 체크에 이의가 있으면 7일 안에 신고 화면에서 이의를 제기할 수 있습니다.

### 4-3. 긴급 상황

- 모임 화면에 "긴급 신고" 버튼을 둡니다. 누르면 112 번호를 크게 보여 주고, 운영팀에 즉시 알림을 보냅니다.
- 운영팀은 긴급 신고를 받으면 신고자에게 먼저 연락하고, 상대 계정을 우선 이용 정지한 뒤 확인합니다.

| 신고 종류 | 1차 조치 | 처리 목표 |
|---|---|---|
| 불법 촬영, 성적 촬영물 | 즉시 가림 → 확인 후 삭제·영구 정지, 수사기관 협조 | 즉시 가림, 24시간 안에 판단 |
| 모임 중 위험 (긴급) | 상대 계정 우선 정지, 신고자 연락 | 즉시 |
| 초상권 침해 (내가 나온 사진) | 본인 확인 후 삭제 | 24시간 |
| 명예훼손, 사생활 침해 | 판단이 어려우면 임시조치(가림, 최대 30일) 후 양쪽에 통지 | 24시간 안에 1차 조치 |
| 괴롭힘, 혐오, 사칭 | 가림, 제재 단계 적용 | 24시간 |
| 사진 도용 (저작권) | 원작자 확인 후 삭제 | 72시간 |
| 스팸, 무단 홍보 | 삭제, 제재 단계 적용 | 72시간 |
| 노쇼 이의 | 모임장·참여자 확인 | 7일 |

### 5-2. 권리침해 게시물 (정보통신망법 제44조의2 절차)

1. 명예훼손이나 사생활 침해를 주장하는 사람이 삭제를 요청합니다.
2. 운영팀이 판단해 삭제하거나, 판단이 어려우면 최대 30일 동안 가립니다(임시조치).
3. 요청한 사람과 게시한 사람 모두에게 조치 사실을 알립니다.
4. 게시한 사람은 이의를 제기할 수 있습니다. 30일 안에 결론이 나지 않으면 다시 판단합니다.
5. 이 절차를 이용약관에 적어 둡니다 [14].

### 5-3. 제재 단계

| 단계 | 조치 | 해당 예 |
|---|---|---|
| 1 | 경고 (알림) | 가벼운 비매너, 첫 무단 홍보 |
| 2 | 7일 이용 제한 (글쓰기·모임 신청 불가) | 경고 후 반복, 괴롭힘 |
| 3 | 30일 이용 제한 | 2단계 후 반복 |
| 4 | 영구 정지 | 3단계 후 반복 |
| **즉시 영구 정지** | 단계 없이 바로 | 불법 촬영, 성희롱·성적 요구, 폭력·위협, 미성년자 대상 행위, 타인 명의 가입 |

- 모든 신고와 조치는 관리자 페이지에 기록합니다 (누가, 언제, 무엇을, 왜).
- 영구 정지한 사람은 CI로 재가입을 막습니다. 이를 위해 탈퇴·정지 계정의 CI를 얼마 동안 보관할지 처리방침에 적습니다 (8절 확인 필요).
- 제재를 받은 사람은 7일 안에 이의를 제기할 수 있습니다.

### 5-4. 불법촬영물이 신고되면

1. 게시물을 즉시 가리고 공유·다운로드를 막습니다.
2. 확인되면 삭제하고 게시자를 영구 정지합니다.
3. 피해자에게 디지털성범죄피해자지원센터(한국여성인권진흥원)와 경찰 신고 방법을 안내합니다.
4. 수사기관 요청에 대비해 게시 기록(계정, 시각, 파일 해시)은 보관합니다. 촬영물 원본을 보관해도 되는지는 변호사에게 확인합니다 (8절).

## 7. 약관과 처리방침에 들어갈 항목

직접 쓰기보다 공정거래위원회 표준약관과 개인정보보호위원회 작성지침을 바탕으로 변호사 검토를 받는 것을 권합니다.

**이용약관**

- 서비스 내용, 가입 자격(만 19세 이상, 본인인증), 계정 관리
- 게시물의 권리와 이용 허락 범위 (사진 저작권은 촬영자에게 있고, 앱은 서비스 표시에 필요한 만큼만 이용)
- 금지 행위와 제재 (3절, 5-3절), 무관용 조항
- 권리침해 게시물 처리와 임시조치 (5-2절)
- 오프라인 모임에서 생긴 일에 대한 플랫폼의 책임 범위 (플랫폼은 모임의 주최자가 아님)
- 실비 참가비의 수령과 분쟁 (MVP는 앱 밖 거래)
- 서비스 변경·중단, 분쟁 해결, 관할 법원

**개인정보 처리방침**

- 처리 항목과 목적: 가입(카카오·Apple 계정 정보), 본인인증(CI/DI, 이름, 생년월일, 성별), 활동(유형, 연령대, 지역, 모임 이력, 출석 기록), 게시물
- 보유 기간: 탈퇴 즉시 파기가 원칙. 재가입 제한용 CI, 신고·제재 기록, 법령상 보관 기록은 예외와 기간을 적음
- 처리 위탁과 국외 이전: 서버(Supabase 등), 이미지 CDN(Cloudflare 등), 본인인증 대행, 분석 도구. 받는 자, 국가, 항목, 목적, 기간
- 14세 미만 아동의 개인정보를 수집하지 않는다는 내용
- 정보주체의 권리와 행사 방법, 개인정보 보호책임자 연락처
- 위치정보: 기기 위치를 수집하지 않는다는 내용, 사진 GPS를 지운다는 내용
