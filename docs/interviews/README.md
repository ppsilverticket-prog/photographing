## 1. 기록 규칙 (먼저 읽기)

> ⚠️ **이 저장소는 공개(public)입니다.** 누구나 이 폴더를 읽을 수 있습니다.

| 저장소에 올려도 됨 | 저장소에 올리면 안 됨 (저장소 밖 비공개 공간에만) |
|---|---|
| 가명 ID (P01~P15) | 실명, 전화번호, 이메일, SNS 아이디 |
| 그룹, 연령대, 장비, 구 단위 지역 | 동호회·카페·동아리 이름, 직장·학교 |
| 가린 인용 ("[동호회A]에서는...") | 녹음 파일, 녹취 원문, 얼굴이 나온 사진 |
| 가정별 판정과 근거 | ID와 실명 대조표, 스크리닝 폼 응답 원본 |

- 파일 이름은 `P01_운영자.md` 형식입니다. [`_template.md`](_template.md)를 복사해 인터뷰 당일 24시간 안에 채웁니다.
- ID는 인터뷰한 순서대로 붙입니다. 그룹과 관계없이 P01, P02, ... 순서입니다.
- 대조표, 녹음, 폼 응답은 개인 구글 드라이브 같은 비공개 공간에 둡니다. 동의서에 적은 보유 기간(검증 종료 후 3개월)이 지나면 삭제합니다.
- 실수로 개인정보를 커밋했다면 파일만 지워서는 부족합니다. git 기록에 남아 있으므로 바로 알려 주세요.
