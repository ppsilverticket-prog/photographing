# 포토그래핑 앱 (iOS · Android)

Expo SDK 57(React Native, TypeScript)로 만든 앱 프로토타입입니다. 하나의 코드로 아이폰과 안드로이드 앱을 만듭니다.

- 웹 미리보기: https://claude.ai/artifact/TEMKut17TkMk4dGiJ2JwW9 (비공개. 휴대폰 브라우저로 열면 앱처럼 보여요)
- 지금 단계: **프로토타입**. 서버 없이 기기 메모리에서만 동작하고, 앱을 다시 열면 처음 상태로 돌아갑니다.

## 내 휴대폰에서 실행하기

컴퓨터(맥·윈도우 모두 가능)와 휴대폰이 필요합니다. 맥이 없어도 아이폰에서 볼 수 있습니다.

1. 컴퓨터에 [Node.js](https://nodejs.org) LTS 버전을 설치합니다.
2. 휴대폰에 **Expo Go** 앱을 설치합니다 (App Store, Google Play).
3. 이 저장소를 내려받고 터미널에서 실행합니다.
   ```bash
   cd mobile
   npm install
   npx expo start
   ```
4. 터미널에 QR 코드가 나오면 아이폰은 카메라 앱으로, 안드로이드는 Expo Go 앱으로 찍습니다.
5. 컴퓨터와 휴대폰이 같은 와이파이에 있어야 합니다. 회사 와이파이처럼 막혀 있으면 `npx expo start --tunnel`을 씁니다.

| 모임 채팅 | 참여 확정자만 입장, 긴급 신고(112 안내) |

| 신고 | 신고 사유 9가지, 함께 차단 |
| MY · 설정 | 신뢰도·참석·노쇼·늦은 취소, 활동 정보 변경, 차단 목록, 계정 삭제, 프로토타입 도구 |

**프로토타입 도구** (설정 맨 아래): 창립 모임장으로 전환해 모임 열기를 체험하거나, 노쇼를 추가해 신청 제한을 확인할 수 있습니다. 인터뷰에서 시연할 때 씁니다.

규칙은 [`../docs/07-operations-policy.md`](../docs/07-operations-policy.md)를 따릅니다. 기기 위치는 수집하지 않고(D1), 사진의 위치 정보는 지웁니다(D2). 1:1 메시지는 없습니다(D6).

## 개발

```bash
npm test           # 규칙과 상태 테스트 (25개)

npm run lint       # 린트
```

폴더 구조와 작업 규칙은 [`AGENTS.md`](AGENTS.md)에 있습니다.

## 실제 서비스로 가려면 남은 일

| 순서 | 일 | 비고 |
|---|---|---|
| 1 | Supabase 프로젝트 만들고 DB 적용, 앱 연결 | DB 구조는 완성 ([`../docs/08-database.md`](../docs/08-database.md)). 계정 생성은 운영자가 직접. `src/data/store.tsx`의 동작을 서버 호출로 바꾸고, 온보딩의 연령대 질문은 본인인증 결과로 대체 |
| 2 | 카카오 로그인, Sign in with Apple | 네이티브 모듈이라 개발 빌드(EAS) 필요. Expo Go로는 못 봄 |
| 3 | PASS 본인인증 연동 | 본인인증 대행사 계약 필요 |
| 4 | 카카오맵 | 카카오 개발자 앱 키 필요 |
| 5 | 이미지 업로드 서버와 서버 쪽 EXIF 제거 | 운영정책 D2의 두 번째 단계 |
| 6 | 푸시 알림 (승인, 모임 전날 알림, 신고 결과) | expo-notifications |
| 7 | 관리자 페이지 (신고 처리, 제재) | 운영정책 5절 |
| 8 | 앱 아이콘·스플래시, 앱 이름·번들 ID 확정 | 이름·상표 확인 후 (`../docs/02-name-check.md`) |
| 9 | EAS로 TestFlight·내부 테스트 배포 → 클로즈드 베타 | Apple 개발자 계정(연 99달러), Google Play 개발자 계정(1회 25달러) |

알려진 한계: 한글 글꼴(IBM Plex Sans KR)이 굵기마다 약 2.8MB라 앱 용량이 큽니다. 3가지 굵기만 싣고 있으며, 출시 전에 글꼴을 서브셋으로 줄이거나 시스템 글꼴로 바꾸는 것을 검토합니다.
